# PDF双栏刷题阅读器

PC 端双栏 PDF 刷题阅读器：左侧「题本」、右侧「解析」，按刷题节奏联动。技术栈 **Electron + Vue 3 + TypeScript + PDF.js**。

## 功能（P0 MVP）

- **双栏打开**：左右分别打开题本与解析 PDF，栏头显示文件名与页码，分隔条可拖动、双击均分
- **比例同步滚动 + 主从模式**：默认「题本主、解析从」，滚动题本时解析按比例跟随；可切换主从方向、可开关同步
- **缩放同步**：Ctrl+滚轮 / 工具栏缩放，支持双侧联动（可关）
- **解析遮罩**：半透明遮罩防偷看答案，三种模式——点击露出 / 悬停露出 / 橡皮擦擦除；一键显示/隐藏整页解析、一键重置
- **悬停形状自定义**：悬停露出支持圆形/方形/横条/竖条四种形状（hover 模式下工具栏切换）
- **画笔标注**：在 PDF 上自由绘制笔迹，可选颜色与粗细，按文件+页持久化，缩放后位置不变；**支持撤回**（Ctrl+Z / 工具栏按钮，画错的笔迹用撤回删除）
- **文本框标注**：点击添加文字备注，双击编辑、拖动移动、一键删除，按文件+页持久化；未输入的空白框自动清理
- **书签**：一键记录双侧位置与**所属文件**，支持标签（错题/重点/存疑）与筛选；点击书签自动切换到书签关联的题本/解析并双侧跳转（当前文件不一致时自动打开对应文件）；**标签直接点选**（彩色标签按钮，点击标记/再点取消）；**面板可拖动调宽**（左缘拖拽条，宽度记忆）
- **帮助**：工具栏「帮助」按钮或 **F1**，展示全部快捷键与操作提示；**快捷键可自定义**（帮助里点击「改」后按新键，键位冲突自动交换，可恢复默认）
- **老板键（伪装模式）**：默认 **Ctrl+Shift+B** 一键伪装——窗口标题（任务栏程序名）变为「PDF对比器」、两侧栏名变为「文档A / 文档B」、工具栏品牌同步切换；再按一次恢复。伪装仅本次运行有效（不持久化、不跨机同步），键位可在帮助里自定义
- **性能**：分页虚拟滚动懒加载（只渲染可视页 ±2），数百页秒开、低内存
- **主题**：日间 / 夜间 / 护眼米黄 / 纯黑白印刷
- **界面风格**（工具栏「⋮」菜单切换）：瑞士国际主义（直角·粗黑线·黑白反转）/ 中国水墨（宣纸噪点·宋体楷书·竖排朱砂印章·墨迹笔触·远山纹样）/ 新粗野主义（粗黑边·高饱和撞色·硬阴影按压）；「⋮」菜单收纳风格/主题/重置遮罩/帮助等低频功能，工具栏保持单行

## 开发

```bash
npm install        # 安装依赖
npm run dev        # 开发模式（热更新）
npm run build      # 构建
npm run typecheck  # 类型检查
npm run dist       # 打包 Windows 安装包（electron-builder）
```

> 若 Electron 二进制下载失败（国内网络），执行：
> `$env:ELECTRON_MIRROR="https://npmmirror.com/mirrors/electron/"; node node_modules/electron/install.js`

## 数据存储

- **业务数据**（书签、设置）：默认存 `文档\PDF刷题阅读器\data\`，JSON 文件原子写入
- **本机偏好**（窗口状态、数据目录路径）：`%APPDATA%\pdfview\config.json`
- 双机同步方案见 `技术设计文档.md` 第 8 节（同步中心导出/导入 zip）

## 目录结构

```
electron/   主进程 + preload（窗口、文件对话框、JSON 原子写 IPC）
src/
  core/     与 UI 解耦的核心逻辑（PageMapper / SyncEngine / MaskManager / PdfDocument）
  stores/   Pinia 状态（viewer / settings / mask / bookmark）
  components/ PdfViewer / PdfPage / SplitPane / Toolbar / BookmarkPanel / PasswordDialog
  storage/  JSON 读写封装
```
